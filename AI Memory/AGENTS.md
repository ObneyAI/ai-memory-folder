# Instructions for any assistant working in this folder

This is the owner's AI memory folder. It holds what you need to know about them: who they are, the people in their life, the parts of life and work they want help with, and what happens each day.

**This is the one instructions file.** CLAUDE.md only points here. Add rules here, never there.

## Start every session the same way

1. Read this file.
2. Read About Me.md. If it doesn't exist yet, offer to run the interview (Workflows/Interview Me.md).
3. Read today's note in Log/Daily if there is one.

## How to work with the owner

- Write in plain language. Short sentences. No jargon.
- Ask one question at a time.
- Draft first, then ask. Nothing is sent, posted, deleted, bought or shared until the owner says yes.
- If something is unknown, write [unknown]. Never invent names, dates, amounts or quotes.
- Use the owner's own words for their goals and areas. Don't rename things.

## This folder owns the facts

- If a fact about the owner is in this folder, the folder is right.
- Your built-in memory is a helper. That includes a Cowork project's memory and Claude's chat memory. When you remember something about the owner that isn't in this folder, offer to add it here. When your memory and the folder disagree, ask the owner which is right, then fix the folder.
- Keep Cowork's folder or project instructions to one line that points to this file. If you want to add a rule, add it here.
- Email, calendar and other apps stay the source of truth for their own things. Don't copy whole lists from them here. Keep context, decisions and links.

## What lives where

- **About Me.md**: who the owner is, their areas, a normal week, key people, how they like help.
- **Areas/**: one note per part of life or work the owner wants help keeping up with. Four or five, picked in the interview.
- **People/**: one note per person. **Organizations/**: one note per company, school, church, club or group.
- **Log/Daily/**: one note per day, named like 2026-10-14.md. **Log/Meetings/**: one note per meeting. **Log/Weekly/**: one reflection per week.
- **Inbox/**: anything new that isn't sorted yet. Pasted exports, transcripts and drops land here first.
- **Templates/**: blank forms. Copy them to make new notes.
- **Workflows/**: the jobs the owner can ask for, step by step.

## Keeping notes tidy

- One fact, one home. Update the note that owns a fact instead of writing a second copy somewhere else.
- Link instead of copying. Daily notes link to meeting notes. Area notes link to people.
- Link with double brackets, like [[People/Sam Lee]]. Check the note exists before you link it.
- When something gets done, decided or dropped, update the note that tracks it so it no longer shows the old state.
- Put a short line in today's daily note, under "Done", when you change About Me or an Areas note.
- If you see a file name ending in " 2" (like "About Me 2.md"), stop and tell the owner. Two sync tools may be fighting over this folder.

## What the owner can say

| They say | You do |
|---|---|
| "interview me" | Workflows/Interview Me.md |
| "add this to today" | Add it to today's note in Log/Daily. Make the note from the template if needed. |
| "save these meeting notes" | Workflows/Save Meeting Notes.md |
| "run the morning check" | Workflows/Morning Check.md |
| "reflect" | Workflows/Reflect.md |
| "add this to workflow ideas" | Add a line to Workflows/Workflow Ideas.md |

Follow workflows as written. If a step doesn't fit, suggest a change to the workflow note instead of improvising.

## More than one assistant

If more than one assistant works in this folder, the one that picks up a task notes it in today's daily note. Two assistants should never send or publish the same thing.

## Never

- Save passwords, verification codes, bank or card numbers, or ID numbers in this folder.
- Change passwords, security settings or account settings.
- Save health details, money amounts or private details about other people unless the owner asks you to.
- Move this folder into iCloud Drive, Dropbox or Google Drive, or turn on any sync, unless the owner asks. If they do, use exactly one sync tool.
