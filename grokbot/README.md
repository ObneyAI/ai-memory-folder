# AI Memory for Grok Bot

Your notes stay in one folder on the bot’s computer.
This version starts with 3 files and no subfolders.

## Start with your agent

Give the [repository page](../README.md) URL to your assistant.
Ask it to make your AI Memory folder and start setup.
Agents must follow [INSTALL.md](../INSTALL.md) from the same revision.

## Manual download

1. Download [ai-memory.zip](ai-memory.zip).
2. Extract the ZIP, or give it to your bot.
3. Follow [Start Here](AI%20Memory/Start%20Here.md).

Only the AI Memory folder is needed for personal use.

## Setup

The assistant asks a few interview questions.
You examine the answers before the assistant saves About Me.
You then use those notes for a real task.
In a new session, the assistant reads the saved notes again.

The setup file tracks these steps.
After your completion check, the assistant moves lasting information and removes the setup file.

## Growth

The assistant creates folders when their first notes are useful.
About 7–10 files is an early check point.
About 12–13 files is a later check point.
Let useful work determine the number of files.

Areas, People, Organizations, Inbox, Logs, Workflows, Templates, and Guides can appear through use.
The starting instructions contain the rules for their creation.
