# Start Here

Grok Bot saves your notes on its computer.
You can ask the bot for a copy.
The folder grows when you need more notes.

## Start

1. Give your bot access to this AI Memory folder.
2. Send this request:

> Read AGENTS.md in my AI Memory folder. Start my setup from _setup.md.

3. Examine the folder path that the bot reports.

If the folder is still in a ZIP, ask your bot to extract it into your private workspace.
Type your answers or send a voice message if the bot can transcribe voice messages.
You examine the summary before the bot saves About Me.

## Next session

Start a new conversation with the same bot.
Say: “Use my AI Memory folder. Read AGENTS.md. Run the morning check.”
The bot uses your saved notes.

## Useful requests

- Interview me.
- Add this to today.
- Save these meeting notes.
- Run the morning check.
- Reflect.
- Send me a copy of my folder.

## Routines

Try the morning check before you schedule it.
You choose the schedule and timezone.
The bot shows each routine for approval before it creates the routine.
App connections and routines are optional.

## Files

AGENTS.md contains lasting instructions for the assistant.
_setup.md records setup progress.
After your completion check, the bot removes _setup.md.
Your notes stay in the folder.
