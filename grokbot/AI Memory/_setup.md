# Setup

This file tracks setup across sessions.
The assistant updates the checklist after it examines each result.
The owner can stop at any step.

## Progress

- [ ] Make sure that you can read this folder.
- [ ] Save the owner’s accepted interview answers in About Me.
- [ ] Agree where the owner saves things.
- [ ] Complete one useful task with that saved context.
- [ ] Use the saved context in a new session.
- [ ] Examine the notes with the owner.
- [ ] Complete the file copy checks below.

## Session record

**Last completed step:** None.
**Next step:** Make sure that you can read the folder.
**Previous session identifier:** Unknown.
**Unfinished items:** None recorded.
**Temporary answers:** None recorded.

## Step 1: Folder access

Read AGENTS.md.
Read Start Here.
Tell the owner which folder you can use.
Do not create a test file or other folders for this check.
If access fails, give the platform instructions from Start Here.

## Step 2: Interview

Use the interview procedure in AGENTS.md.
If you already know the owner, start with a review of that knowledge.
Tell the owner that you will review what you know about them.
Name the sources: built-in memory, connected apps, and existing routines.
Ask for permission before you examine them.
Present a draft as your current understanding, with its sources.
Ask the owner to accept, change, or remove each item.
Then ask only about missing, old, or uncertain facts.
Ask one question at a time.
Save the accepted profile in About Me.
Open the saved note for the owner when the app can show file previews.
Record unfinished answers here only if the owner wants to keep them.

## Step 3: Where you save things

Read About This Folder.
Ask how and where the owner saves files.
Ask which folder you can explore.
Read the folder and file names in that folder.
Describe the structure that you find.
Suggest up to three improvements.
Save the agreed system in `Where Things Are.md`.
Move or rename files only after the owner approves a plan.
The owner can skip this step.

## Step 4: Useful work

Offer one small task based on the owner’s current priority.
Complete the task the owner selects.
Save a result only when a saved result is useful.
Use the growth plan in AGENTS.md for any new note.
Explain a new folder when its first note is necessary.
Do not create the full folder plan.

## Step 5: New session

Ask the owner to start a new conversation in this folder.
In that conversation, read About Me and the related saved work.
Show how the saved information helps with the next request.
Use an available session identifier or the owner’s confirmation to make sure that this is a new session.
Do not treat a later message in the same conversation as a new session.

## Step 6: Final check

Show the notes created so far.
Ask whether they are correct and useful.
Make the corrections the owner requests.
Ask whether the owner wants to finish setup.
Their agreement permits removal of this setup file after the checks below.

## Step 7: Move and remove

Follow the Complete setup procedure in AGENTS.md.
Move accepted facts into the notes that own them.
Resolve or move unfinished items.
Update Start Here for the notes and routines that exist.

Make sure that no permanent instruction depends on this file.
Record setup completion in About Me.
Examine each saved result.
Remove only this file.

Do not create empty folders, skills, routines, or templates to finish setup.
