# Later: Sync

Leave this for later. Get the folder working on one computer first.

When you want the same folder on a second computer, or in the cloud, pick exactly one way to sync it. Only one.

Two sync tools on the same folder fight each other. You end up with copies named like "About Me 2.md", and nobody knows which one is right. We learned this the hard way.

## Pick one
- **Obsidian Sync**, if you read the folder in Obsidian.
- **iCloud Drive, Google Drive or Dropbox**, if you already use one of them for everything.
- **Git**, only if you or someone helping you already knows it.

## Before you turn it on
- Check whether a sync tool already watches this folder. On many Macs, iCloud already syncs the Documents folder. On many PCs, OneDrive does. If one does, that's your one. Moving the folder into iCloud Drive, Dropbox or Google Drive counts as turning one on.
- If you see a file with " 2" at the end of its name, stop. Two tools are syncing. Turn one off, then ask your assistant to merge the copies.

## About the cloud
Cowork can run some tasks in the cloud while your laptop is closed. A folder on your computer is only reachable while the Claude desktop app is open. Getting this folder to the cloud is a sync question too, so the same rule applies: one way, not two.
