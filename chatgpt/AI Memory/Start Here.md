# Start Here

Your assistant saves useful facts in this folder.
The folder grows when you need more notes.

## Start with Codex

1. Open the desktop app.
2. Add this AI Memory folder as a local project.
3. Select AI Memory as the primary folder.
4. Send this request:

> Start my setup from _setup.md.

Type your answers or use voice in this task when available.
The assistant asks a few questions.
You examine the summary before it saves About Me.

## Start with ChatGPT Work

1. Select local Work in the desktop app.
2. Give the task access to this AI Memory folder.
3. Send this request:

> Read AGENTS.md in this folder. Start my setup from _setup.md.

If local Work is unavailable, use Codex with the same folder.

## Next session

Start a new conversation in the same local project.
Say: “Read AGENTS.md. Run the morning check.”
The assistant uses your saved notes.

## Useful requests

- Interview me.
- Add this to today.
- Save these meeting notes.
- Run the morning check.
- Reflect.

## Files

About This Folder explains the folder and gives ideas to try.
AGENTS.md contains lasting instructions for the assistant.
_setup.md records setup progress.
After your completion check, the assistant removes _setup.md.
Your notes stay in the folder.
