# Start Here

Your assistant saves useful facts in this folder.
The folder grows when you need more notes.

## Start

1. Open Claude on your computer.
2. Create a Cowork project with this AI Memory folder.
3. Put this line in the project instructions:

> Read AGENTS.md in this folder before you start work.

4. Send this request:

> Start my setup from _setup.md.

Type your answers or use dictation.
Claude asks a few questions.
You examine the summary before Claude saves About Me.

## Next session

Start a new conversation in the same project.
Say: “Run the morning check.”
The assistant uses your saved notes.

## Useful requests

- Interview me.
- Add this to today.
- Save these meeting notes.
- Run the morning check.
- Reflect.

## Files

About This Folder explains the folder and gives ideas to try.
AGENTS.md contains lasting instructions for the assistant.
CLAUDE.md points Claude Code to those instructions.
_setup.md records setup progress.
After your completion check, the assistant removes _setup.md.
Your notes stay in the folder.

If a voice conversation cannot use the folder, ask for a written summary.
Bring that summary into your Cowork project.
