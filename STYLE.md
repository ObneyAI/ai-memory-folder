# Writing rules

Use ASD-STE100 Issue 9 for participant text and agent instructions.
The official standard contains the writing rules and dictionary.

## Rules

- Use direct commands for procedure steps.
- Keep instruction sentences within 20 words.
- Keep description sentences within 25 words.
- Give one action in each instruction sentence.
- Use active voice.
- Put a necessary condition before its action.
- Keep one subject in each paragraph.
- Keep each paragraph within six sentences.
- Give information in the order that the reader needs it.
- Use the same term for the same item.
- Use approved dictionary meanings and parts of speech.
- Use technical terms only for their stated meanings.
- Keep interface labels, file names, and owner quotations exact.

## Kit terms

These terms name objects and processes in this kit.

| Term | Meaning |
|---|---|
| Owner | Person whose notes are in the folder |
| Assistant | AI system that works on those notes |
| Note | Saved Markdown file |
| Area | Responsibility with a separate note |
| Profile | Personal information in About Me |
| Session | One conversation with the assistant |
| Task | Work the owner asks the assistant to do |
| Workflow | Saved procedure for a task |
| Template | Blank note format |
| Routine | Scheduled task |
| Setup | Initial folder access, interview, and use of saved notes |
| Memory | Information retained by an assistant outside these notes |
| Sync | Service that copies file changes between devices |
| Manifest | File list with source paths and content digests |
| Setup map | The note `Setup Map.md`, which shows how the owner's setup works |
| Connector | App connection that the assistant can use |
| Credential name | Name of a saved login, without its secret value |

Use file, folder, app, chat, ZIP, Markdown, and SHA-256 as computing terms.
Use save, copy, download, upload, extract, update, and delete for their computing operations.
Use product names as product names.
Do not replace a simple approved word with a technical term.

## Checks

Read each procedure for its action order and meaning.
Use the official dictionary for uncertain general words.
Use `python3 build.py` for file counts, links, archive integrity, and sentence-length checks.
The script does not prove full dictionary or grammar compliance.
Do not describe its result as formal ASD-STE100 certification.
